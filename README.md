# AKIOTOO — сайт тату-студии (Костанай)

Статический сайт: HTML + CSS + один JS-файл без библиотек. Хостинг — GitHub Pages, сборка не нужна.

## Что где менять

| Что | Где |
|---|---|
| WhatsApp, Instagram, Telegram, адрес, 2GIS, координаты | `js/config.js` (незаполненное помечено `TODO`) |
| Фото работ | заменить `assets/works/work-01.webp … work-12.webp` (вертикальные 4:5, ~1000×1250, до ~150 КБ) |
| Добавить работу | положить `work-13.webp` и дописать строку в `works` в `js/config.js` |
| Сколько работ на главной | `homeWorks` / `homeWorksMobile` в `js/config.js` |
| Тексты | `index.html` |
| Цвета, размеры шрифтов, отступы | начало `css/style.css` (`:root`) |
| Тема | по умолчанию светлая; тёмная — по ссылке `?theme=dark`. Сменить тему по умолчанию: `DEFAULT` в скрипте в `<head>` обоих HTML |

## Устройство

```
index.html, works.html
css/style.css        mobile-first; 768px — планшет; 1024px — ПК; сетка 12 колонок, контейнер 1280px
js/config.js         данные
js/main.js           ссылки, работы, лайтбокс, карта, появление блоков, параллакс баннера (ПК)
assets/fonts/        Manrope (текст) и Cormorant Garamond (заголовки), woff2, кириллица+латиница
assets/img/          AVIF + WebP: hero 800/1200 (телефон, 4:5) и 1600/2000 (ПК), лого, фото мастера
assets/works/        фото работ (сейчас заглушки)
assets/source/       оригиналы заказчика
```

- Рукописные «Запись» и «в Костанае» — SVG-контуры (шрифт Amatic SC), отдельный маркерный шрифт не грузится.
- Карта: Leaflet + тайлы 2GIS, грузится только при подходе к блоку (старый iframe-виджет 2GIS не работает, новый требует API-ключ).
- Анимации: параллакс баннера на ПК и одноразовое появление блоков (opacity + 20px, 0.6s). При `prefers-reduced-motion` всё отключено.
- Параллакс: слой `.hero__media` с `data-speed`. Новые слои (например, рука на прозрачном фоне) — ещё один `.hero__media` со своим `data-speed`.
